Privacy Policy

This page describes the current behavior of the Draftia Windows application.

1. Local application data

Draftia stores application data locally on the user's PC. Team notes, champion pool data, schedule data, and other information are not transmitted to the developer unless the user deliberately shares them for support.

2. Riot Games account and API data

Draftia currently does not use the Riot Games Web API to retrieve player or match data and does not require users to sign in with a Riot Games account.

3. External links

Draftia may provide links that open third-party services in the user's browser. Those services operate under their own privacy policies and terms.

4. Support

If a user contacts the developer for support, information included voluntarily in the request may be used only to investigate and respond to that request.

5. Changes

This policy may be updated if Draftia's functionality changes. The latest version will be published on this site.
