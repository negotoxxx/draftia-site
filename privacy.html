Privacy Policy

Draft version — confirm that this matches the final application before publication.

1. Local application data

Draftia is designed to store its application data locally on the user's PC. The developer does not receive the team notes, champion pool data, schedule data, or other information stored locally by the application unless the user deliberately provides that information for support.

2. Riot Games account and API data

Draftia currently does not use the Riot Games Web API to retrieve player or match data and does not require users to sign in with a Riot Games account.

3. External links

Draftia may provide links that open third-party services in the user's web browser. Those services operate under their own privacy policies and terms.

4. Support

If a user contacts the developer for support, information included voluntarily in the support request may be used only to investigate and respond to that request.

5. Changes

This policy may be updated when Draftia's functionality changes. The current version will be published on this site.
